# Flight Analytics & Pricing Intelligence Dashboard

## 📌 Project Overview

An interactive Power BI dashboard developed to analyze flight data
across airlines, routes, pricing, journey duration and stop patterns.

The project combines Power Query, DAX and Power BI to transform
raw flight data into an interactive business intelligence solution.

## 📊 Dataset

- Records: 10,683 flights
- Period: March–June 2019
- Key dimensions:
  - Airline
  - Source
  - Destination
  - Route
  - Date of Journey
  - Total Stops

## 🛠️ Tools & Technologies

- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization

## 📈 Dashboard Pages

### 1. Overview
Provides a high-level view of flight volume, pricing,
duration and route patterns.

### 2. Airline Analysis
Compares airlines based on flight volume, pricing,
duration and stop patterns.

### 3. Route & Airport
Analyzes source airports, destinations and popular routes.

### 4. Price & Duration
Analyzes ticket prices, journey duration and stop patterns.

### 5. Flight Details
Provides detailed flight-level information with
interactive drill-through.

## ⚡ Power BI Features

- Interactive slicers
- Synced slicers
- DAX measures
- Drill-through
- Report page tooltips
- Dynamic titles
- Conditional formatting
- Page navigation
- Interactive filtering
